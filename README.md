# CPP-OOP

Daily practice repo for Object-Oriented Programming in C++ — covering my college OOP course syllabus and beyond.

## 📚 Learning Path

Following this sequence:
1. [CodeWithHarry](https://youtube.com/@CodeWithHarry) — C++ OOP fundamentals
2. [The Cherno](https://youtube.com/@TheCherno) — Deeper OOP + Modern C++
3. Standalone resources for gaps (copy constructors, deep vs shallow copy)

## 🗂️ Structure

| Folder | Topic |
|---|---|
| `01_Classes_and_Objects` | Basics of classes, objects, attributes, methods |
| `02_Arrays_of_Objects_and_Passing_Objects` | Object arrays, passing objects to functions |
| `03_Static_Data_Members_and_Methods` | Static members, class-level data |
| `04_Friend_Functions` | Friend functions and access |
| `05_Friend_Classes` | Friend classes |
| `06_Constructors` | Default, parameterized, overloaded constructors |
| `07_Copy_Constructor` | Deep vs shallow copy |
| `08_Destructor` | Object cleanup |
| `09_Inheritance` | Single, multiple, multilevel, hierarchical, hybrid |
| `10_Ambiguity_Resolution` | Resolving diamond problem & multiple inheritance conflicts |
| `11_Virtual_Base_Class` | Solving diamond inheritance |
| `12_Polymorphism` | Overloading, overriding, virtual & pure virtual functions |
| `13_Abstract_Base_Class` | Abstract classes & interfaces |
| `14_File_Handling` | Reading/writing files in C++ |
| `15_Exercise_Programs` | Practice problems applying multiple concepts |
| `16_Modern_CPP` | Move semantics, smart pointers, Rule of Five (Cherno-exclusive) |
| `Notes/` | Concept notes + interview questions |
